GBA Bridge Finance

跨境贸易金融智能分析与产品推荐系统 — 完整架构、使用与开发指南

1项目概述

GBA Bridge Finance（湾区融桥）是一个面向大湾区跨境贸易中小企业的智能金融分析平台。 系统通过 OCR 文档解析、交叉验证、风险评估、现金流预测和 RAG 产品匹配， 为企业提供从交易资料到金融产品推荐的全流程 AI 辅助分析。

核心价值

  • 连接交易资料 — 上传订单/合同/发票/物流/付款通知，OCR 自动结构化提取
  • 看清经营与现金流 — 多币种现金流预测、资金缺口分析、场景模拟
  • 匹配金融服务 — 基于工银产品知识库的 RAG 推荐，可解释、可追溯
  • 持续跟进交易 — 交易后监控、动态预警、风险重算提醒
边界声明：AI 辅助分析，不构成信贷审批；正式申请、合规审查、风险评估与最终授信由 ICBC 按现有流程完成。

线上地址： https://frontend-six-blush-39.vercel.app

4后端设计

4.1 框架与运行时

FastAPI 应用

后端使用 FastAPI（Python 异步 Web 框架）构建，入口文件为 backend/app/main.py。

  • ASGI 模式：基于 Starlette/Uvicorn，支持异步请求处理
  • 依赖注入：通过 Depends(get_db) 管理数据库会话生命周期
  • 自动文档：访问 /docs 获取 Swagger UI，/redoc 获取 ReDoc
  • CORS 中间件：允许跨域请求（开发环境）
  • 静态文件：本地开发时挂载 /uploads 目录

Serverless 适配

在 Vercel Serverless 环境中，后端通过 api/index.py 包装为 ASGI 应用：

# api/index.py — Vercel Python Serverless Function 入口
import sys, os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), "..", "backend"))
os.environ["VERCEL"] = "1"
os.environ["GBA_DB_PATH"] = "sqlite:///:memory:"
os.environ["UPLOAD_DIR"] = "/tmp/uploads"
from app.main import app  # 导出 ASGI app 供 Vercel 调用
  • 内存数据库：StaticPool 共享单一连接，确保表结构跨请求可见
  • 懒加载：get_db() 在首次请求时初始化 engine + seed
  • 临时文件：上传文件存储到 /tmp/uploads

4.3 核心服务

📄 OCR 服务

ocr_service.py

  • 支持 PDF / 图片 / Excel
  • Tesseract OCR 引擎 + PyMuPDF
  • 文档类型自动分类（订单/合同/发票等）
  • 字段提取与置信度评分
  • 低置信度字段标记需人工验证

🔗 文档理解

doc_understanding.py

  • 统一数据结构转换
  • 跨文档交叉验证
  • 金额/日期/名称一致性检查
  • 交易完整度评分 (0-100)
  • AI 摘要生成

🔍 风险引擎

risk_engine.py

  • 5 维度评估：
  • 1. 文档风险（缺失/冲突）
  • 2. 交易对手风险
  • 3. 交易风险（物流/日期）
  • 4. 融资风险（集中度）
  • 5. 汇率与流动性风险

💱 现金流服务

cashflow_service.py

  • 多币种现金流时间线
  • 资金缺口计算（金额+天数）
  • 场景模拟（延迟/汇率变动）
  • 4 种默认场景批量模拟
  • 流动性缓冲检查

🎯 产品匹配

product_matcher.py

  • SimpleRAG 检索增强生成
  • 基于关键词倒排索引
  • 交易阶段识别 (5 阶段)
  • 工银产品知识库匹配
  • 推荐理由 + 知识引用
  • 无外部 LLM 依赖，完全离线

7使用说明

在线访问

直接访问 https://frontend-six-blush-39.vercel.app

页面操作指南

企业端

  1. 从首页点击 "进入应用" 或 "企业端入口"
  2. 在 Dashboard 页面查看交易概览，选择一笔交易进入分析
  3. 在 Documents 页面上传文档（PDF/图片/Excel），系统自动 OCR
  4. 在 Graph 页面查看交易关系图（买方/卖方/供应商/文档）
  5. 在 Cashflow 页面查看多币种现金流预测与资金缺口
  6. 点击 "风险分析" 按钮触发 5 维度风险评估
  7. 点击 "生成推荐" 获取 RAG 产品匹配结果
  8. 在 Report 页面生成预审报告

RM 工作台

  1. 从首页点击 "RM 工作台"
  2. 查看所有交易的全局视图（风险等级、文档状态、推荐数量）
  3. 进入具体交易，确认 OCR 低置信度字段
  4. 添加风险备注、请求补充材料
  5. 确认金融服务后，可提交至 ICBC 正式流程

监控中心

  1. 从首页或导航栏进入 Monitoring
  2. 查看交易后监控事件（发货更新、付款到账、逾期预警等）
  3. 查看审计日志，追溯全部操作记录

代码修改指南

修改后端 API

  1. 编辑 backend/app/main.py（源文件）
  2. 同步修改 frontend/backend/app/main.py（部署副本）
  3. 本地测试：python -m uvicorn app.main:app --reload
  4. 提交并推送：git add -A && git commit && git push
  5. 部署：cd frontend && npx vercel --prod

修改前端页面

  1. 编辑 frontend/app/ 下的 .tsx 文件
  2. 本地测试：cd frontend && npm run dev
  3. 构建验证：npm run build
  4. 提交并推送
  5. 部署：cd frontend && npx vercel --prod

修改数据模型

  1. 编辑 backend/app/models.py 和 frontend/backend/app/models.py
  2. 如需种子数据，同步编辑 seed.py
  3. 删除本地 .db 文件，重新启动后端自动建表
  4. 测试通过后提交部署

关键配置文件

vercel.json — 路由配置

{
  "rewrites": [
    {
      "source": "/api/(.*)",
      "destination": "/api/index"
    }
  ]
}

api/index.py — Serverless 入口

import sys, os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), "..", "backend"))
os.environ["VERCEL"] = "1"
os.environ["GBA_DB_PATH"] = "sqlite:///:memory:"
os.environ["UPLOAD_DIR"] = "/tmp/uploads"
from app.main import app

next.config.ts — 开发环境代理

// 生产环境: vercel.json 处理 rewrite
// 开发环境: 代理到 localhost:8000
async rewrites() {
  if (process.env.NODE_ENV === "production") return [];
  return [{ source: "/api/:path*", destination: "http://localhost:8000/api/:path*" }];
}

部署步骤

# 1. 确保代码已提交
cd bridge-finance
git add -A
git commit -m "your changes"
git push origin main

# 2. 部署到 Vercel (从 frontend/ 目录)
cd frontend
npx vercel --prod --yes

# 3. 验证部署
# 页面: https://frontend-six-blush-39.vercel.app/
# API:  https://frontend-six-blush-39.vercel.app/api/health
# 文档: https://frontend-six-blush-39.vercel.app/docs
Vercel 自动检测： 项目根目录存在 package.json → 检测为 Next.js 项目； 同时存在 requirements.txt / pyproject.toml + api/*.py → 自动构建 Python Serverless Function。 两者在同一项目中共存。

10角色与权限

企业用户 (enterprise_user)

  • 上传交易文档（订单/合同/发票/物流/付款通知）
  • 查看交易分析结果（风险/现金流/推荐）
  • 查看交易关系图
  • 生成预审报告
  • 查看自己企业的交易与文档

RM 客户经理 (rm)

  • 查看所有分配企业的交易概览（RM Dashboard）
  • 确认 OCR 低置信度字段
  • 编辑/补充交易信息
  • 请求企业补充材料
  • 添加风险备注
  • 确认金融服务推荐
  • 提交至 ICBC 正式流程（触发边界声明）

风险团队 (risk_team)

  • 查看监控中心 — 全局交易事件
  • 处理风险预警（发货/付款/逾期/汇率）
  • 查看审计日志 — 全操作追溯
  • 评估系统性风险趋势
